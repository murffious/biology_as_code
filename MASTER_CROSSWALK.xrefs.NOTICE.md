# MASTER_CROSSWALK.xrefs.tsv — attribution and licence

**A sidecar, not a second crosswalk.** `MASTER_CROSSWALK.tsv` is generated from a
VMH export and gated by `make crosswalk-check`, which compares it byte for byte
against `normalize(extract)`. Enrichment written into it would break that gate and
erase the distinction the gate protects: what VMH said, versus what we added. So
the added cells live here, one row per cell, each naming its own source.

Generated by `tools/enrich_crosswalk_xrefs.py`. Never hand-edit it.

## What is withheld, and why

MNXref also offers KEGG and HMDB identifiers for these compounds. They are **not**
in this file. Their terms forbid what this repository's Apache-2.0 licence grants:

- **KEGG** — *"Non-academic users must understand that KEGG is not a public
  database, nor is it a publicly funded database. Non-academic use of KEGG requires
  a commercial license."* (<https://www.kegg.jp/kegg/legal.html>, page last updated
  2024-10-01, read 2026-09-07.)
- **HMDB** — *"Use and re-distribution of the data, in whole or in part, for
  commercial purposes requires explicit permission of the authors and explicit
  acknowledgment of the source material."* (<https://hmdb.ca/about>, as quoted
  verbatim in the `chem_xref.tsv` header.)

`--include-restricted` emits them. Do not commit that output without resolving the
terms first; `tests/test_crosswalk_xrefs.py` fails if a restricted cell is shipped.

Note that `MASTER_CROSSWALK.tsv` already ships 1,095 `kegg:` and 659 `hmdb:` cells
inherited from VMH. This file does not add to that exposure — it declines to.

## Fail-closed rules

1. **Only OPEN cells are filled.** A populated cell is a value VMH supplied; this
   file never rewrites one.
2. **Disagreements are reported, never applied.** Where an independent source
   contradicts a populated cell it goes to `MASTER_CROSSWALK.xrefs.conflicts.tsv`.
   153 cells are in that state. A conflict is a review item, not a correction.
3. **Deprecated identifiers are dropped.** MNXref marks superseded accessions
   `secondary/obsolete/fantasy identifier` and prefixes them `M_`. Filling a cell
   with one is worse than leaving it OPEN.

## What this changes about the VMH exposure

`MASTER_CROSSWALK.NOTICE.md` lists four ways out if commercial use is ever needed.
The third is *"rebuild the cross-references from each registry directly rather than
from VMH's mapping."* This file is a measurement of how far that has got: **2,379
populated cells are independently corroborated by MNXref** — 825 `chebi`, 867
`kegg`, 581 `hmdb`, 106 `seed`. Those specific cells no longer rest on VMH's
curatorial join alone.

It is a measurement, not the remedy. The remedy needs `name` dropped and the whole
mapping rebuilt; corroborating a cell does not retroactively unmake the extraction.
