## Thesis

Nutrition fails when it **accounts** (calories, macros, slogans) instead of **executing** (packets through gates under host state).

This project standardizes the **interfaces**:

- typed food packets  
- gate vs bound  
- claim audit that stops when a gate is closed  

All three are executable: see the [claim auditor](claim-auditor.md).

## For engineers

Build against the constitution:

- fail closed when data is missing  
- never promote soft verbs (`supports`, `boosts`, `detox`) to law without a typed relation  
- never L1→L5 tunnel (food → disease slogan without mechanism)
