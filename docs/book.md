**Biology as Code: Standardizing Nutrition Science for Preventive Medicine** —
by Paul Murff. Coming soon.

The book and this repository are separate works that argue the same case from
two directions. The book makes the argument: that diet-related chronic disease
is, at its root, a data problem — nutrition science runs on unstandardized
measurements, unversioned definitions, and claims that delete their own context.
This repository is the existence proof: the same discipline expressed as
running code — typed law cards, fail-closed simulation, provenance-graded data,
and a claim auditor that shows its citations.

Read the code, then the book tells you why it had to be written this way.
Read the book, then the code shows you it can actually be done.
