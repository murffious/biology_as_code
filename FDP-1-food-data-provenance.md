# FDP-1: Food Data Provenance Declaration — moved

The FDP-1 specification now has its own canonical home and its own citable DOI:

## → https://github.com/murffious/fdp-1

This repository (`biology_as_code`) is a **reference implementation** of FDP-1 — a
Python package that ingests foods, runs digestion, and can emit FDP-1 declarations —
together with the [`MASTER_CROSSWALK.tsv`](MASTER_CROSSWALK.tsv) nutrient→metabolite
join. The **normative specification**, its **reference validator**, and the **worked
example** live in the `fdp-1` repository linked above.

A specification and its implementation are deliberately separate artifacts with
separate DOIs.
