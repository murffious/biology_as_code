# bcaa_catabolism

Branched-chain amino acid (BCAA) catabolism: leucine, isoleucine, and valine. Shared trunk: transamination → branched-chain keto acid dehydrogenase (BCKDH, MSUD enzyme). Then diverge: Leu → ketogenic (acetyl-CoA / acetoacetate); Val → glucogenic (succinyl-CoA); Ile → both.

- **Graph:** `pathway.mermaid` (auto)
- **Tests:** `tests.md` + `tests/test_pathway_packs.py`
