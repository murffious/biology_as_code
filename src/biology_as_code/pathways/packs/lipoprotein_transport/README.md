# lipoprotein_transport

Lipoprotein-mediated transport of cholesterol and triglycerides. VLDL carries cholesterol out of the liver; LDL delivers it to tissues; HDL performs reverse cholesterol transport back to the liver.

- **Python module:** `biology_as_code.pathways.cholesterol_pathway`
- **Graph:** `pathway.mermaid` (auto)
- **Tests:** `tests.md` + `tests/test_pathway_packs.py`
