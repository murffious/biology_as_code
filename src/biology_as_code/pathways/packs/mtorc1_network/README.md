# mtorc1_network

mTORC1 growth network. Amino acids (leucine via the Rag GTPases) and insulin/IGF (PI3K→Akt→TSC2→Rheb) converge to activate mTORC1, which drives protein synthesis (S6K1, 4E-BP1) and lipogenesis (SREBP) while shutting down autophagy (ULK1). AMPK opposes it (double-negative feedback).
