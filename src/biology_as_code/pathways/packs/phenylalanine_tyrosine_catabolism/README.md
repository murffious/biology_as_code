# phenylalanine_tyrosine_catabolism

Phenylalanine and tyrosine catabolism. Phe is hydroxylated to Tyr by phenylalanine hydroxylase (PAH, BH₄ cofactor) — the PKU enzyme. Tyr proceeds via homogentisate to fumarate (glucogenic) + acetoacetate (ketogenic). Teaching compression of the full multi-enzyme cascade.
