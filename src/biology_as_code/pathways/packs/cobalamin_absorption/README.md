# cobalamin_absorption

Vitamin B12 (cobalamin) absorption requires gastric intrinsic factor (IF). Dietary B12 is released in the stomach, binds IF, and the IF–B12 complex is absorbed in the terminal ileum via cubam receptor teaching path. Failure poles: IF deficiency (pernicious anemia), ileal disease.

- **Python module:** `biology_as_code.pathways.meal_critical_pathways`
- **Graph:** `pathway.mermaid` (auto)
- **Tests:** `tests.md` + `tests/test_pathway_packs.py`
- **Gold template:** `packs/glycolysis/glycolysis_extra/`

Tier: FLOW teaching. Not an external product score.
