# aa_nitrogen_disposal

Amino-acid nitrogen disposal hub. Most amino acids transfer their α-amino group to α-ketoglutarate (aminotransferases → glutamate). Glutamate dehydrogenase releases free NH₄⁺; aspartate donates the second N into the urea cycle. Carbon skeletons exit as α-keto acids toward glucogenic or ketogenic fates. Links to existing urea_cycle graph.
