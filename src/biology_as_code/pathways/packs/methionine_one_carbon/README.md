# methionine_one_carbon

Methionine and one-carbon metabolism. Met is activated to S-adenosylmethionine (SAM), the universal methyl donor. After methyl transfer, SAH → homocysteine. Homocysteine is remethylated to Met (methionine synthase, B12 + 5-methyl-THF) or committed to cysteine via transsulfuration (CBS, B6).
